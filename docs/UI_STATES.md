# Windows 客户端页面与状态清单

视觉系统采用机动橙、企业中性色、Segoe UI/微软雅黑和低动效；Windows 客户端与管理网页共享品牌资产。

## 页面

| 页面 | 核心内容 | 主操作 |
|---|---|---|
| 首次启动 | 产品说明、网络检查、激活入口 | 开始激活 |
| 输入激活码 | 单字段激活码表单 | 验证激活码 |
| 确认身份 | 姓名、员工编号、部门 | 确认并激活 |
| 启动中 | Harness、Runtime、网关检查进度 | 重试或查看诊断 |
| 主壳 | 内嵌 Harness、员工菜单、运行状态 | 使用 Harness |
| 账号与额度 | 姓名、部门、月度金额、RPM、TPM、并发 | 刷新 |
| 更新中心 | 四组件版本、通道、更新说明 | 检查/下载安装 |
| 诊断 | 脱敏状态、版本、错误编号 | 复制诊断信息 |

## 激活状态机

```text
idle → validating → identity-confirmation → activating → success
         ├─ invalid / expired / redeemed ─→ retry
         └─ offline / server-error ───────→ retry
identity-confirmation ── cancel ──────────→ idle
```

- 加载 200ms 后才显示，按钮保留“验证激活码/确认并激活”文字并内置进度指示。
- 错误在输入框下方显示具体原因和恢复动作；服务端错误同时展示可复制 Support ID。
- 确认页只展示服务端返回的姓名、工号和部门，不允许编辑。
- 网络失败保留用户已输入的激活码；确认超时则回到输入页。
- 成功信息不能只依赖颜色；完成后明确告知“已激活为：姓名”。

## Harness 运行状态

主壳固定使用一条 48px 标题栏。左侧只保留公司图形标与“超智能 Harness”；右侧依次为文字状态、员工菜单和 Windows 三个窗口按钮。重启不作为常驻主按钮，收纳在员工菜单中，避免与窗口级操作争夺层级。

| 状态 | 用户反馈 | 可执行操作 |
|---|---|---|
| stopped | Harness 尚未启动 | 启动 |
| starting | 展示分阶段进度，5 秒后补充说明 | 取消、查看诊断 |
| running | 显示本地运行状态 | 重启、打开日志 |
| failed | 具体失败原因和错误编号 | 一键重试、查看诊断 |
| gateway-offline | 保留本地页面，说明公司网关不可达 | 重试连接 |
| update-required | 解释最低版本和截止时间 | 立即更新 |

启动采用有界恢复策略：安装后首次启动先等待安装器退出；单次失败会清理 Harness 子进程和 WebView2 实例，最多自动尝试三次。如果当前 WebView2 宿主进程仍不可恢复，软件会自动换进程继续一次且禁止循环。恢复进程仍失败时停止进度动画，显示诊断编号、“重新启动”和“打开诊断目录”。

## 外观状态

| 策略 | 标题栏来源 | 适用场景 |
|---|---|---|
| 跟随工作台（默认） | Harness 页面浅色/深色；页面加载前回退到 Windows | 视觉最连贯 |
| 跟随 Windows | Windows 应用主题 | 员工偏好系统一致性 |
| 浅色 | 固定浅色 | 明亮办公环境 |
| 深色 | 固定深色 | 暗光环境 |

主题同步只传递 `light`/`dark`，不传递网页内容。系统高对比度开启时优先使用 Windows 系统色。

## 更新状态

`idle → checking → available → downloading → verifying → ready → installing → success`，任一步失败均保留已验证的稳定版本并提供重试。签名或哈希失败属于不可继续错误，不允许“仍然安装”。

## 可访问性基线

- 所有控件有可访问名称且可用键盘操作，焦点样式可见；
- 错误通过文字、图标和颜色共同表达，并关联到输入框；
- 不阻止粘贴激活码，Enter 可提交；
- 状态变化通过可访问的状态文本播报；
- 动效必须尊重“减少动态效果”系统设置。
- 自绘标题栏必须保留窗口拖动、双击最大化、边缘缩放、最大化贴靠、右键/Alt+Space 系统菜单和可访问名称；
- 浅色、深色和高对比度下，标题、状态、员工菜单与窗口按钮均保持可辨认。

## 管理网页

管理网页部署后可通过企业配置的管理入口（例如 `https://admin.harness.example.com/admin/`）访问，包含三个主页面：

| 页面 | 核心内容 | 主操作 |
|---|---|---|
| 运行概览 | 员工、部门、可用激活码、活跃 Key 计数和员工摘要 | 刷新、查看员工 |
| 员工与部门 | 员工资料、状态、访问期限、月额度、RPM、TPM、并发 | 单人添加、设置期限、启用、禁用、受限删除、下载模板、CSV 导入 |
| 激活码管理 | 员工搜索与多选、有效期预设、自定义北京时间、替换策略 | 批量生成、复制或下载 CSV |

- 管理凭据只放在当前浏览器 `sessionStorage`，退出或关闭会话后不持久保存；
- 添加员工使用单列表单；禁用与删除使用可键盘关闭的确认对话框，删除需输入员工编号；
- 添加表单明确展示当前网关上限：月度金额 72,000 元、RPM 600、TPM 2,000,000、并发 20；浏览器先行校验，服务端越界返回 HTTP 400 和中文原因；
- 禁用会撤销全部活跃虚拟 Key 并作废未使用激活码；已签发过 Key 的员工禁止物理删除；
- 员工访问期限提供“长期有效”和“指定结束时间”；已到期员工显示“已到期”，重新启用前必须先延长期限或改为长期；
- 激活码默认选择“1 天（推荐）”，支持 1 小时、8 小时、1 天、3 天、7 天、30 天及最长 90 天自定义，并始终预览准确北京时间；
- 未认证为 401，界面回到登录页；业务错误在页面顶部显示中文恢复提示；
- 激活码明文只在批量生成响应和当前页面显示一次，刷新后不能找回；
- 空列表、加载、成功和错误均有独立文字状态；表格可横向滚动；
- 窄屏使用抽屉导航，全部交互目标不小于 42–44px，并支持键盘焦点和减少动态效果。
