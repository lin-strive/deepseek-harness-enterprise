# 品牌与 Logo 资产

公司名称：超智能战斗轮椅有限公司

品牌配置：`branding/brand-template.json`

## 可用资产

| 文件 | 用途 |
|---|---|
| `info/logo-generated-source.png` | 图形标生成源，保留透明背景，供重新排版和人工矢量化使用。 |
| `info/logo-v2-horizontal.png` | 横向组合标，适用于客户端标题区、安装程序和管理后台。 |
| `info/logo-v2-mark.png` | 方形图形标，适用于应用图标、托盘图标和启动页。 |
| `info/logo.png` | 横向组合标的兼容尺寸版本。 |

所有交付文件均为透明背景 PNG。横向组合标的中文全称必须完整显示，不应压缩、拉伸或拆分重排。

## 使用规则

- 浅色背景使用石墨灰与机动橙标准版本；
- Logo 四周至少保留图形高度约 10% 的安全留白；
- 横向空间不足时使用方形图形标，不要强行缩小公司全称；
- 不添加阴影、描边、透视、旋转或未经确认的英文副标题；
- 正式印刷或大尺寸物料发布前，应基于当前图样再制作人工校准的 SVG/AI 矢量源文件。

## 设计说明

图形标以车轮为基础轮廓，用向前的闪电切口表达智能驱动、速度与工程韧性，石墨灰承担稳定感，机动橙只用于关键识别。横向版本使用系统中文字体精确排印公司全称，避免图片生成模型产生文字错误。

运行 `scripts/generate-brand-assets.ps1` 可从图形源重建全部尺寸。正式印刷或商标注册前，仍应由设计人员依据当前图样绘制并校准 SVG/AI 矢量源文件。
