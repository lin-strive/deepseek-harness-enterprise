# 超智能 Harness 设计简报

## 产品身份

面向公司内部开发人员的 Windows AI 开发工具。产品承担启动、激活、状态、更新和诊断职责；核心 Agent 工作台继续使用 DeepSeek Harness。

## 主要用户

- 第一次接触 Agent Harness 的普通开发人员；
- 需要稳定恢复工作区和会话的高频用户；
- 负责激活、额度、版本和故障处理的管理员。

## 体验目标

- 用户无需理解 Node.js、端口、Runtime 或模型供应商配置；
- 首次安装到成功发起任务的路径短且可恢复；
- 更新、连接和激活状态清晰，不依赖查看日志；
- 公司身份和策略明确，但不伪装成 DeepSeek 官方软件；
- 高风险操作、密钥和诊断数据边界明确。

## 已知约束

- 首版仅支持 Windows 10/11 x64；
- 使用 WebView2；
- 不修改 DeepSeek Harness 上游 UI 源码；
- 不提供个人模型 Provider 入口；
- 不记录提示词、代码或回复正文；
- 必须支持键盘导航、缩放和高对比度；
- 所有状态文案使用简体中文。

## 已确认视觉方向

- 设计风格：克制、清晰的企业开发工具；
- 公司主色：沿用已确认 Logo 的机动橙；
- 字体：Windows 系统中文字体栈，优先 Segoe UI 与微软雅黑；
- 动画强度：低，仅用于状态过渡和加载反馈；
- 界面语言：简体中文。

## Learned constraints

- 示例品牌使用 `info/logo-v2-horizontal.png` 与 `info/logo-v2-mark.png`；换牌时必须从新的图形源重新生成，不得直接给现有位图改色、拉伸或增加英文副标题。
- 激活确认必须显式显示员工姓名、工号和部门后再签发虚拟 Key；原因是无设备绑定条件下需要降低激活码误用风险。
- Windows 桌面外壳不能使用固定浅色双层顶栏包裹可切换浅色/深色模式的 Harness，系统最小化、最大化和关闭控件必须与公司外壳视觉整合；原因是当前窗口标题栏、公司操作栏与 Harness 形成三套相互割裂的界面层级。
